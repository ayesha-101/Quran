# بستان القرآن

تطبيق ويب لمراجعة وحفظ الفاتحة وجزء عمّ وجزء تبارك للأطفال. نسخة تجريبية للعائلات.

## المصادر
- نص المصحف بالرسم العثماني: [quran-json](https://www.npmjs.com/package/quran-json)، من موسوعة القرآن الكريم QuranEnc.
- التلاوة: الشيخ محمود خليل الحصري (المصحف المعلّم)، آية آية، من [q7h_husary_muallim](https://github.com/Raf0707/q7h_husary_muallim). الاستخدام التجاري يحتاج التأكد من الترخيص قبل الإطلاق.

## التشغيل
موقع ثابت بدون خطوة بناء: `index.html` + مجلد `audio/`. ينشر على Vercel باختيار Framework Preset: Other.
التقدّم ينحفظ على جهاز المستخدم (localStorage).
